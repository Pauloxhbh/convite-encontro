# Convite para um encontro 🥺

Um convite divertido feito em HTML, CSS e JavaScript, com tudo em um único arquivo.

- O botão **Não** muda de lugar e alterna frases engraçadas a cada clique.
- O botão **Sim** solta confetes e continua para escolher o encontro.
- Funciona no computador e no celular, sem instalar dependências.

## Como abrir

Baixe os arquivos e abra `index.html` no seu navegador.

As escolhas ficam apenas na página e não são enviadas automaticamente. Combine os detalhes do encontro diretamente com a outra pessoa.
